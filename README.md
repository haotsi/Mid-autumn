# 月满金陵 · 北大楼中秋夜

以南京大学北大楼为主景的中秋主题 3D 场景。夜色、满月、灯笼、桂花树和茶席共同组成一幅校园赏月画面。

## 运行
### 本地运行
需要 Node.js 18 或更高版本。项目依赖已经放在仓库中，不需要联网安装 npm 包。

```powershell
npm start
```

然后访问 <http://127.0.0.1:5173>。请通过本地服务访问页面，不要直接双击 `index.html`，否则浏览器可能限制模块和 GLB 模型的读取。
### GitHub托管网址
[月满金陵 · 北大楼中秋夜](https://haotsi.github.io/Mid-autumn/)  （若不稳定可尝试本地运行方案）
## 交互

- 拖动场景：环绕北大楼观察
- 滚轮或双指缩放：调整观察距离
- `灯火夜景 / 静谧月夜`：切换灯光氛围
- `归位`：用平滑动画回到初始构图
- `赏月寄语`：显示中秋祝福
- 点击月亮或灯笼：显示一条祝福
- `写下心愿`：输入心愿并点亮一盏升向月光的祈愿灯
- 从北大楼背面观看时，月亮会淡出隐藏；回到正面后重新出现

祈愿灯功能会在浏览器本地保存最近 12 条心愿，只保存在当前设备，不会上传到服务器。

页面支持桌面端和移动端，并会尊重系统的“减少动态效果”设置。

## 目录

```text
assets/north-building.glb  北大楼 3D 模型
app.js                    场景入口、灯光、相机和交互
courtyard.js              灯笼、茶席、桌椅和桂花庭院
moon.js                   本地生成的月面纹理
camera-home.js            归位动画
index.html                页面结构
style.css                 页面视觉样式
server.mjs                轻量本地静态服务器
vendor/                   本地 Three.js 运行文件
```

## 资源说明

北大楼模型复制自 MyWeb 项目的 `north-building.glb`。满月纹理、灯笼、庭院家具、桂花树、星光和云雾由本项目在浏览器中生成。页面不依赖外部图片、CDN 或在线接口；Three.js 的许可证保存在 `vendor/LICENSE`。
